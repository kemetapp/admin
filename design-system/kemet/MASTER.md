# KEMET — نظام التصميم (النسخة 0.3)

تطبيق توصيل أكل — **واجهة العميل فقط** (MVP) — React Native + Expo — عربي RTL — **أسوان** — **طابع فرعوني معاصر**.

---

## 1. الفكرة والاتجاه

**الاسم المؤقت:** كيميت / KEMET
**الوعد:** «أكل البلد، لحد باب البيت»
**الجمهور:** سكان أسوان والمناطق حولها، 18–40 سنة، يطلبون أكل مصري ونوبي ومطاعم محلية.
**الوظيفة الأساسية:** الوصول لصنف، إضافته للسلة، وإتمام الطلب في أقل من دقيقة.

### الاتجاه البصري: «فرعوني معاصر»

هوية مستوحاة من معابد أسوان والبرديات، لكن منفّذة بحداثة: مساحات واسعة، صور أكل حقيقية،
وزخرفة محدودة تعمل كإطار — مش كخلفية.

**الفكرة:** «كيميت» هو الاسم القديم لمصر، وأسوان بوابة المعابد (فيلة، إدفو، أبو سمبل).
الطابع الفرعوني بيظهر في **تفاصيل مضبوطة** فقط: الخرطوش، الشمس المجنحة، لوتس النيل،
عقد المعبد، والخط الذهبي الرفيع — مش في رسومات كرتونية أو هيروغليفي مقروء.

**قرارات مقصودة:**
- **الزيتي هو اللون الأساسي** (`#4F5B2A`) — هادي، ترابي، ومختلف عن منافسين الأحمر.
- **الكريمي خلفية التطبيق** (`#FBF6E8`) — دفء ورقي بدل الأبيض البارد.
- **الطيني الأسواني** (`#B4562F`) لمسة ثانوية فقط: مسار الخريطة، أيقونة الموقع، وتفاصيل صغيرة.
- **الزعفران للشارات** (`#D9A24A`) — ستيكر المحل الورقي.
- **ذهب المعبد** (`#B8862F`) للحدود والفواصل والنقوش — مش لنص صغير (تباينه 3:1).
- **الرموز الفرعونية زخرفة فقط:** الخرطوش للشعار، الشمس المجنحة في الهيدر والبانرات،
  اللوتس قبل العناوين، وعقد المعبد لصور الفئات والترحيب.
- **صور الأكل هي البطل** — مفيش رسومات كرتونية أو إيموجي.
- **زرار السلة بارز في نص الشريط السفلي** — أقرب إجراء في التطبيق.
- **شارات ورقية مائلة قليلًا** بدل الشارات المستطيلة العادية.

**تجنّبنا:** الأحمر كعلامة أساسية، الخلفية البيضاء الباردة، السيريف، الكروت المتطابقة بزوايا موحّدة،
الهيروغليفي الكامل، رسومات الفراعنة والأهرامات الكرتونية، والذهبي اللامع بكميات كبيرة.

## 3. الخطوط

| الدور | الخط | الأوزان |
|---|---|---|
| العناوين والأرقام الكبيرة | **Alexandria** | 600 / 700 / 800 |
| النص وواجهة الاستخدام | **IBM Plex Sans Arabic** | 400 / 500 / 600 |

**المقاسات:** 12 / 14 / 16 / 18 / 22 / 28 / 34
**ارتفاع السطر:** 1.65 للنص العربي، 1.25 للعناوين الكبيرة.
**الأرقام:** أرقام لاتينية (4.8، 25–35) لأنها أسرع في القراءة داخل التطبيقات المصرية.
**العملة:** `ج.م` بحجم أصغر بـ 2px من الرقم.

> ليه مش Noto Naskh؟ لأن التطبيق سريع وحديث؛ Alexandria هندسي وواضح على الشاشات الصغيرة،
> وIBM Plex Sans Arabic مصمم أصلًا لواجهات الاستخدام.

## 4. المسافات والأشكال

- **مقياس 4/8:** 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48
- **الحواف الداخلية للشاشة:** 20px
- **نصف القطر:** 12 (عناصر صغيرة) · 18 (كروت) · 26 (شيتات) · 34 (كروت كبيرة)
- **الظل:** `0 8px 24px rgba(22,33,29,.08)` — ظل واحد فقط في النظام.
- **مساحة اللمس:** 48×48 كحد أدنى، مع توسيع المنطقة المخفية للأيقونات الصغيرة.
- **الحركة:** 180ms للضغط، 240ms للدخول، 160ms للخروج، `prefers-reduced-motion` محترم.

## 5. المكوّنات

**اللغة الزخرفية:** كل رمز له وظيفة واحدة ومكان واحد.
الشمس المجنحة = هيدر وفواصل وبانرات. الخرطوش = الشعار. اللوتس = عنوان قسم.
عقد المعبد = صور الفئات والترحيب. الحد الذهبي = إطار. مفيش رمز بيتكرر كخلفية.

| المكوّن | القاعدة |
|---|---|
| زر أساسي | خلفية زيتي، نص أبيض، ارتفاع 54، نصف قطر 18، حد ذهبي 1px |
| زر ثانوي | حدود 1.5px بلون العلامة، نص زيتي، خلفية شفافة |
| زرار أيقونة | 44×44، خلفية كارت، حدود `--line` |
| شيب | ارتفاع 38، حدود 1px، مفعّل = زيتي فاتح + نص زيتي |
| حقل إدخال | ارتفاع 52، نصف قطر 15، حدود `--line`، أيقونة يمين، عين لكلمة السر |
| بانر دعائي | نسبة **2:1** بالظبط (332×166 على شاشة 372)، صورة كاملة + تدرّج زيتي داكن + إطار ذهبي داخلي + شمس مجنحة، عنوان + كود، كاروسيل أفقي بنقاط |
| كارت منتج (ترند) | عرض 150، صورة 150×100، اسم + اسم المطعم + السعر + زر إضافة |
| بانر مطعم | بعرض الشاشة، ارتفاع 124، صورة كاملة + تدرّج داكن + إطار ذهبي داخلي، **اسم المطعم + التصنيف + وقت التجهيز**، تحت بعضها رأسيًا |
| خرطوش | شكل بيضاوي مسطح القاعدة بحد ذهبي — للشعار وحرف «ك» فقط |
| شمس مجنحة | قرص شمس + 3 ريشات لكل جناح، عرض 76–132، ذهبي — مرة واحدة في الشاشة |
| لوتس | أيقونة 13–15px قبل عناوين الأقسام فقط |
| عقد معبد | صورة بنصف قطر علوي كامل (33px لـ66، 160px لـ300) وقاعدة شبه مستقيمة |
| خلفية بردية | تدرّج ذهبي خفيف أعلى الشاشة + خطوط رأسية 1px كل 6px بشفافية 1.8% |
| ستيكر | زعفران، ميل −3°، نص 11px بوزن 600 |
| ستِبر كمية | 3 أزرار 36×36، الرقم في النص |
| شريط سفلي | 5 مواضع، السلة بارزة في النص بقطر 60، حد ذهبي علوي رفيع |
| شيت | من الأسفل، نصف قطر 26، مقبض ذهبي 44×4 |
| شاشة ترحيب | صورة بشكل قوس 300×356 + شمس مجنحة + شارة + شيب عائم، نقاط 3، عنوان 30px، زر أساسي |
| شاشة دخول / تسجيل | شعار خرطوش + رجوع، عنوان 26px، حقول 52px، زر أساسي، فاصل «أو»، زر Google، رابط تبديل |

## 6. خريطة الشاشات

| # | الشاشة | الوظيفة |
|---|---|---|
| 01 | ترحيب 1 | «كل أكل البلد في مكان واحد» + تخطي + زر يلا نبدأ |
| 02 | ترحيب 2 | «اطلب في ثواني وتابع كل خطوة» |
| 03 | ترحيب 3 | «تابع طلبك لحد باب البيت» + إنشاء حساب / تسجيل دخول |
| 04 | تسجيل الدخول | موبايل + كلمة سر، فاكرني، نسيت كلمة السر، دخول بـ Google |
| 05 | إنشاء حساب | الاسم + الموبايل + كلمة السر، الشروط، تسجيل بـ Google |
| 06 | الرئيسية (أسوان) | الموقع، البحث، بانرات دعائية 2:1، «هتاكل إيه النهاردة؟»، «ترند دلوقتي»، بانرات المطاعم |
| 07 | صفحة المطعم | الغلاف، التصنيف، التقييم، وقت التجهيز، قائمة الأصناف، شريط السلة |
| 08 | تخصيص الصنف | الحجم، الإضافات، الملاحظات، الكمية، الإضافة للسلة |
| 09 | السلة | الأصناف، الكود، الإجمالي، إتمام الطلب |
| 10 | إتمام الطلب | العنوان، الوقت، طريقة الدفع، التأكيد |
| 11 | تتبع الطلب | الخريطة، المندوب، مراحل الطلب |
| 12 | طلباتي | الطلب الحالي + السابق + إعادة الطلب |
| 13 | حسابي | العناوين، الدفع، المفضلة، الإعدادات (موثّقة، غير مرسومة) |
| 14 | نتائج البحث | فلاتر، ترتيب، نتائج (موثّقة، غير مرسومة) |

**أقسام لوحة المعاينة:** الترحيب (01–03) · الحساب (04–05) · التصفح (06–07) · الطلب (08–10) · بعد الطلب (11–12).

**مسار الترحيب:** ترحيب 1 → 2 → 3 → تسجيل الدخول (04) أو إنشاء حساب (05) → الرئيسية (06).
**المسار الأساسي:** الرئيسية (06) → مطعم (07) → تخصيص (08) → سلة (09) → دفع (10) → تتبع (11).
**الحساب:** شاشات 04 و05 تقبل التبديل بينها، وفيها «تخطي» للرجوع للترحيب.

**ترتيب الرئيسية (06) من فوق لتحت:**
1. هيدر أسوان + البحث.
2. **بانرات دعائية 2:1** — كاروسيل أفقي (سلايدين + نقاط).
3. **«هتاكل إيه النهاردة؟»** — صف فئات أفقي.
4. **«ترند دلوقتي»** — المنتجات الأكثر طلبًا (كارت 150px).
5. **«المطاعم»** — بانرات مطاعم كاملة العرض، كل بانر فيه **اسم المطعم + التصنيف + وقت التجهيز**.

**قرار البانرات:** قائمة المطاعم في الرئيسية **مش كروت أفقية** — بانرات كاملة العرض
بارتفاع 124px، صورة الأكل هي الخلفية، والنص فوقها من الأسفل. بتتراكم رأسيًا واحدة تحت
التانية عشان الصورة تاخد مساحتها والاسم يبان من غير ما المستخدم يسحب أفقيًا.

**قرار البانرات الدعائية:** نسبة **2:1** بالظبط، صورة كاملة + تدرّج زيتي داكن + عنوان
وكود خصم. معروضة كاروسيل بسحب أفقي؛ لو المساحة ضاقت أو المستخدم فضّل، تتحول لقائمة رأسية
بنفس النسبة.

## 7. ملاحظات RTL

- `dir="rtl"` على مستوى التطبيق، و`I18nManager.forceRTL` في Expo.
- سهم الرجوع **لليمين**، والشيبس والكروت تنعكس تلقائيًا.
- الأيقونات الاتجاهية (سهم، سكوتر، خريطة) تحتاج مراجعة يدوية — متعكسش الأيقونة نفسها.
- الخريطة لا تنعكس؛ أسماء الشوارع فقط هي اللي تتعامل RTL.
- الأرقام والوحدات تفضل LTR داخل جملة عربية (`25–35 د`).

## 8. إمكانية الوصول

- تباين النص ≥ 4.5:1 في الوضعين.
- كل أيقونة زرار لها `accessibilityLabel` عربي.
- الأيقونات الزخرفية `accessibilityElementsHidden`.
- الأخطاء تحت الحقل مباشرة، وملخص أخطاء عند الإرسال.
- دعم تكبير الخط بدون كسر التخطيط.
- الخريطة لها بديل نصي: «المندوب على بعد 1.2 كم، 18 دقيقة».
- العناصر الزخرفية (الشمس المجنحة، اللوتس، الخرطوش) `accessibilityElementsHidden` — مش محتوى.
